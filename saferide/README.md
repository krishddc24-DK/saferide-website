# SafeRide Website

Static HTML/CSS/JS website generated by the 12-agent pipeline.

## Files

- `index.html` and other `.html` files — one per page (22 pages, plus `404.html`)
- `go/app-store/` and `go/google-play/` — QR code landing pages (forward to the waitlist until launch)
- `style.css` — design tokens and styles (do not edit; regenerate via Kavya)
- `shared.js` — navigation, forms, cookie consent (do not edit; regenerate via Vikram). Settings at the top: `FORM_ENDPOINT`, `GA_MEASUREMENT_ID`
- `assets/` — logo, favicon, social share image, QR codes (SVG for web, PNG for print)
- `sitemap.xml`, `robots.txt`, `site.webmanifest` — SEO and browser files
- `.htaccess` — Apache hosting security config and redirects
- `netlify.toml` — Netlify hosting security config and redirects
- `_headers` — Netlify alternative security config
- `delivery.md` — full project summary, QA results, placeholders to replace, and next steps

## Local preview

Open `index.html` directly in your browser. No build step required.

## Deployment

Choose one of:

- **Apache hosting:** upload the folder and keep `.htaccess`. Remove `netlify.toml` and `_headers`.
- **Netlify:** upload the folder. Keep `netlify.toml` OR `_headers` (not both). Remove `.htaccess`.
- **GitHub Pages, S3, generic static host:** upload the `.html`, `.css`, `.js` files plus `assets/` and `go/`. Configure security headers at the hosting layer; the included `.htaccess` or `_headers` show the recommended values.

After deployment, verify the security headers are active. See `delivery.md` for details.

## At app launch

Point `/go/app-store/` and `/go/google-play/` at the real store listings (in `.htaccess` or `netlify.toml`, and in `go/*/index.html`). Printed QR codes will then open the right store.
